# PANDUAN PENOMORAN & PEMBUATAN SURAT PENGUMUMAN HASIL PSB 2027-2028
**Pesantren Ulul Albaab Sukabumi**

Dokumen ini disusun untuk Admin Super Pesantren Ulul Albaab (Pak Aziz Wijaya) sebagai panduan resmi penomoran dan penerbitan Surat Pengumuman Hasil Seleksi Santri Baru Tahun Pelajaran 2027/2028.

---

## 1. Format Standar Nomor Surat
Format resmi nomor surat pengumuman hasil kelulusan adalah:
```text
012-<KODE>/PSB-PUAS/<BULAN_ROMAWI>/<TAHUN>
```
* **`012`** : Nomor Surat Keputusan (SK) Induk Panitia PSB Tahun Pelajaran 2027/2028.
* **`<KODE>`** : Kode urut berupa **2 huruf abjad** kapital (`AA` .. `AZ`, lalu `BA` .. `BZ`, `CA` .. `CZ`, dst.).
* **`PSB-PUAS`** : Unit Penerimaan Santri Baru - Pesantren Ulul Albaab Sukabumi.
* **`<BULAN_ROMAWI>`** : Bulan penerbitan surat dalam angka romawi (misal November = `XI`, Desember = `XII`, Januari = `I`).
* **`<TAHUN>`** : Tahun masehi penerbitan surat (`2026`).

## 5. Checklist yang Wajib Disesuaikan Sebelum Cetak / Ekspor PDF
Saat mengedit file `Template_Pengumuman_Hasil_PSB_2027-2028_UlulAlbaab.docx`:
1. [ ] **Nomor Surat**: Ganti `012-[KODE_SURAT]` dengan kode surat yang tepat (misal: `012-BB/PSB-PUAS/XI/2026`).
2. [ ] **Nama Calon Santri**: Ganti `[NAMA LENGKAP SANTRI]` dengan nama lengkap (HURUF BESAR / KAPITAL).
3. [ ] **Nomor Pendaftaran**: Ganti `[NO. PENDAFTARAN]` (contoh: `MTA2700046`).
4. [ ] **Kelas dan Jenjang**: Ganti `[KELAS DAN JENJANG]` (contoh: `di kelas VII MTs Putra` atau `di kelas X MA Putra` atau `di kelas VII I'dad Lughowi Putra`).

---

## 6. Standar Penamaan File PDF Hasil Ekspor
Simpan file Word dengan nama:
`012- Pengumuman Hasil PSB 2027-2028 [Nama Santri].docx`

Lalu diekspor (Save As) ke format PDF dengan nama yang sama:
`012- Pengumuman Hasil PSB 2027-2028 [Nama Santri].pdf`

Contoh:
* `012- Pengumuman Hasil PSB 2027-2028 Mahardika Yusran.pdf`
* `012- Pengumuman Hasil PSB 2027-2028 Hanafi Firdaus.pdf`

File PDF inilah yang kemudian di-upload ke menu Pengumuman pada akun Admin Super.
